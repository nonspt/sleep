# 晚安，小宝

宝宝哄睡音乐 PWA，访问 [在线播放器](https://nonspt.github.io/sleep/)。v1.5 共 18 首、六类，每类 3 首：噪声、自然、钢琴、音盒、摇篮、安抚。

嘘声更换为 10 分钟混音：哄宝宝的嘘声实录、多普勒胎心实录和柔和水流背景。水流由溪流录音滤波处理，不是羊水实录。心跳换为完整约 4 分钟成人静息实录；呼吸换为三周龄婴儿睡眠实录，循环延展为 5 分钟。另补入安然钢琴、小星星八音盒和女声哼唱。

每类一排三张圆角卡片，仅显示简短名称。主界面保留音乐选择、播放暂停和循环，控制图标使用本地 SVG。目标 iPhone Air 与 iPhone 17 Pro 竖屏可一屏显示，较短窗口自然滚动。

使用 iPhone Safari 打开，在分享菜单选择“添加到主屏幕”。首次联网打开并保持前台，点击右上角“更多”，确认“全部音乐可离线播放”，之后可用本机缓存播放。旧版 15 首中的 12 首缓存可复用，只准备 6 个更新文件；完整准备后清除 3 个旧文件。关闭旧应用和相关网页再重新打开以启用新版。

全部音源与混音组件均为资源页面标注的 CC0 1.0；作者、来源、许可及循环／混音处理记录见 [音源说明](audio-licenses.json) 和“更多 → 音源说明”。音乐已随项目提供，无需播放时访问音源网站。
