# 晚安，小宝

宝宝哄睡音乐 PWA，访问 [在线播放器](https://nonspt.github.io/sleep/)。v1.4 共六类、15 个音源：白噪声、自然声音、轻柔钢琴、八音盒、摇篮曲、安抚声音。

安抚声音包含轻柔嘘嘘声、平稳心跳（合成，60 次／分钟）和缓慢呼吸。每类一排两到三张圆角卡片，仅显示简短名称；删除卡片插画、时长、播放小按钮及类别计数，增大字号和留白。目标 iPhone Air 与 iPhone 17 Pro 竖屏可一屏显示，较短窗口可自然滚动。主界面保留音乐选择、播放暂停和循环，剩余控制图标使用本地 SVG。

使用 iPhone Safari 打开，在分享菜单选择“添加到主屏幕”。首次联网打开并保持前台，点击右上角“更多”，确认“全部音乐可离线播放”，之后可用本机缓存播放。已有完整音乐缓存可复用，更新后自动补齐新增音源；关闭旧应用和相关网页再重新打开以启用新版。

音源为资源页面标注的 CC0 1.0；作者、来源、许可及处理记录见 [音源说明](audio-licenses.json) 和“更多 → 音源说明”。音乐已随项目提供，无需播放时访问音源网站。

本仓库保存 GitHub Pages 所需静态发布文件，使用 main 分支根目录；未包含本地证书、私钥或开发依赖。iPhone 后台和锁屏播放仍需实机验证。
