# 晚安，小宝 · 宝宝哄睡音乐

12 首音乐，分为白噪声、自然声音、轻柔钢琴、八音盒和摇篮曲五类。SVG 插画与一屏布局适配 iPhone Air、iPhone 17 Pro。

## 使用

发布地址：https://nonspt.github.io/sleep/

用 iPhone Safari 打开网页，分享 → 添加到主屏幕。从主屏幕打开，首次保持联网和前台运行，等待底部显示“全部音乐可离线播放”，之后可离线播放。无需本地证书。

## 文件

仓库保存已构建的页面、SVG 图标、PWA 离线资源和完整 MP3。音源来源、作者、CC0 1.0 许可及处理记录见 audio-licenses.json 和应用的“音源说明”。

iPhone 实际安装、锁屏连续播放仍需实机验收。
